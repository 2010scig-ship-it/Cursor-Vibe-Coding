# 🧠 기억력 짝 맞추기 게임 (Memory Match Game)

카드를 뒤집어 같은 그림의 짝을 맞추는 두뇌 트레이닝 기억력 퍼즐 게임입니다.

![Memory Match Game Preview](public/favicon.svg)

## ✨ 주요 기능 및 특징

1. **다양한 테마 지원**
   - 🐶 동물 친구들 (강아지, 고양이, 판다 등)
   - 🍕 맛있는 음식 (피자, 초밥, 버거 등)
   - 🚩 세계 국기 (한국, 미국, 영국, 일본 등)
   - 💻 IT & 테크 (노트북, 로봇, 게임패드 등)
   - 🚀 신비한 우주 (로켓, 행성, 외계인 등)

2. **난이도 선택**
   - **초급**: 3x4 (총 12장, 6쌍)
   - **중급**: 4x4 (총 16장, 8쌍)
   - **고급**: 4x5 (총 20장, 10쌍)
   - **달인**: 6x6 (총 36장, 18쌍)

3. **풍부한 게임 시스템**
   - **연속 콤보 시스템**: 짝을 연속으로 맞출수록 더 높은 점수와 신나는 효과음 부여
   - **힌트 시스템**: 막힐 때 짝을 찾을 수 있는 힌트 기능 (난이도별 제공 횟수 차등)
   - **효과음 (Web Audio API)**: 카드 뒤집기, 짝 맞춤, 실패, 힌트, 승리 팡파르 효과음 (무음 전환 가능)
   - **승리 축하 애니메이션**: 클리어 시 컨페티(꽃가루) 효과와 승리 팝업
   - **명예의 전당 (리더보드)**: 로컬 스토리지를 활용하여 난이도별 최고 점수 및 클리어 시간 기록 보관

4. **반응형 & 인터랙티브 UI**
   - 모바일, 태블릿, 데스크톱 모든 기기에 최적화된 유려한 3D 카드 뒤집기 애니메이션
   - 키보드 접근성 지원 (`Tab`, `Enter`, `Space`로 카드 조작 가능)

## 🚀 실행 방법

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build

# 테스트 실행
npm test
```
