# 짝 맞추기

같은 그림을 찾아 짝을 맞추는 기억력 카드 게임입니다.

- 쉬움 · 보통 · 어려움 세 가지 난이도
- 시간, 이동 횟수, 남은 짝 표시
- 난이도별 최고 기록 저장
- 카드 뒤집기 · 짝 맞춤 효과음

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 을 엽니다.

## 스크립트

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm test` | 게임 로직 테스트 |
| `npm run build` | 정적 파일 빌드 |
| `npm run preview` | 빌드 결과 미리보기 |
