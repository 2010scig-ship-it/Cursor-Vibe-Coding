# Cursor-Vibe-Coding

## 기억력 짝 맞추기 게임

같은 그림 카드 두 장을 찾아 모든 짝을 맞추는 브라우저 게임입니다. 별도 설치 없이 `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

### 기능

- 난이도 3단계: 쉬움(4×3, 6쌍), 보통(4×4, 8쌍), 어려움(6×6, 18쌍)
- 시도 횟수, 경과 시간, 찾은 짝 수 표시 (첫 카드를 뒤집으면 타이머 시작)
- 카드 뒤집기 3D 애니메이션, 짝이 맞으면 강조 / 틀리면 흔들림 효과
- 난이도별 최고 기록 저장 (시도 횟수가 적은 순, 같으면 시간이 짧은 순 · `localStorage` 사용)
- 키보드(Tab + Enter/Space)로도 플레이 가능, 모바일 반응형 레이아웃

### 실행

```bash
# 그냥 파일을 열거나
open index.html

# 로컬 서버로 실행
python3 -m http.server 8000
# http://localhost:8000 접속
```

### 파일 구성

- `index.html` – 화면 구조
- `style.css` – 스타일과 애니메이션
- `game.js` – 게임 로직
