# 찰칵! 기억 사진관

같은 동물 카드를 찾아 짝을 맞추는 반응형 기억력 게임입니다.

## 실행

별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다. 로컬 서버를 사용하려면:

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`으로 접속하세요.

## 기능

- 쉬움(4×3), 보통(4×4), 어려움(6×4) 난이도
- 이동 횟수, 경과 시간, 연속 성공 및 진행률 표시
- 일시정지, 효과음 켜기/끄기, 새 게임
- 키보드 방향키 및 Space 조작
- 모바일·데스크톱 반응형 화면
