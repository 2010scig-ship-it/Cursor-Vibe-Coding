# 짝 맞추기

같은 그림 두 장을 찾는 기억력 게임입니다.

`index.html`을 브라우저에서 열면 바로 할 수 있습니다.

## 놀이 방법

1. 난이도를 고릅니다. 쉬움은 6쌍, 보통은 8쌍, 어려움은 12쌍입니다.
2. 카드를 눌러 두 장씩 뒤집습니다.
3. 그림이 같으면 그대로 열려 있고, 다르면 다시 뒤집힙니다.
4. 모든 짝을 찾으면 시도 횟수와 시간이 남습니다.

최고 기록은 이 브라우저에 저장됩니다. 시도 횟수가 더 적거나, 같은 횟수에서 더 빠르면 기록이 바뀝니다.

별은 시도 횟수로 매깁니다. 짝 수 대비 1.5배 이하면 별 3개, 2.25배 이하면 별 2개입니다.
